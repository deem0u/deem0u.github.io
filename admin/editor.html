Contact Page Editor

Update and deploy contact information to your GitHub Pages

Setup Instructions

  1. Create a GitHub Personal Access Token:
    Go to GitHub Token Settings → Generate new token (classic) → Select repo scope → Generate token
  2. Paste your token above — it will be stored in your browser's local storage for convenience
  3. Select a contact page to edit, make your changes, and click "Deploy to GitHub"
  4. Changes go live immediately once the commit is successful (GitHub Pages may take 1-2 minutes to update)

Where to store this editor: Save this file as admin/editor.html in your deem0u.github.io repository. Access it at: https://deem0u.github.io/admin/editor.html
