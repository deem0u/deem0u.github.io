Failsafe — retrieve admin key from Cloudflare
  1. Log in at dash.cloudflare.com
  2. Workers & Pages → your Worker → Settings → note the KV namespace
  3. Workers & Pages → KV → open that namespace
  4. Find key admin:key — its value is your admin key
  5. Sign in here with that key, then set a new password in Dashboard → Account

Site Management

Apply changes with Confirm. Maintenance and Lockdown are mutually exclusive. When Divert Emails is off, you can still turn on “Divert to dev” for individual users on their cards in Manage Users. To change these from a script or tool, see SETUP-GUIDE for API details.

  • Divert Emails — Send all notification emails to the dev address instead of recipients.
  • Maintenance — Only contact pages are accessible; editor and signup are blocked.
  • Lockdown — Site access blocked for everyone except admins.
