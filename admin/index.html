Failsafe — retrieve admin key from Cloudflare
  1. Log in at dash.cloudflare.com
  2. Workers & Pages → your Worker → Settings → note the KV namespace
  3. Workers & Pages → KV → open that namespace
  4. Find key admin:key — its value is your admin key
  5. Sign in here with that key, then set a new password in Dashboard → Account
